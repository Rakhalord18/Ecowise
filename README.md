# Ecowise - Website Revamp

Redesign website Ecowise dari versi Webflow yang sebelumnya menjadi lebih modern, bersih, dan profesional menggunakan HTML, Tailwind CSS, dan JavaScript.

## Tentang Project

Ecowise adalah brand dari EcoFuture Labs yang berfokus pada solusi ramah lingkungan untuk mendukung gaya hidup berkelanjutan. Website ini merupakan hasil redesign dari project kolaborasi tim pada program Studi Independen **VINIX 7**.

## Perbaikan dari Versi Sebelumnya

- **Desain Lebih Modern** - UI yang lebih bersih dengan color palette hijau yang konsisten
- **Hierarki yang Jelas** - Penggunaan heading yang tepat dan struktur yang lebih terorganisir
- **CTA Lebih Mencolok** - Tombol call-to-action yang jelas dan menarik
- **Spacing Konsisten** - Padding dan margin yang rapi antar section
- **Fully Responsive** - Optimal di desktop, tablet, dan mobile
- **Better UX** - Navigasi smooth scroll, mobile menu, dan micro-interaction
- **Faster & Lightweight** - Dibangun dengan HTML murni + Tailwind CSS via CDN

## Teknologi yang Digunakan

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework
- **JavaScript (Vanilla)** - Untuk interaktivitas (mobile menu & smooth scroll)
- **Font Awesome** - Icon library
- **Google Fonts (Inter)** - Typography

## Fitur

- Hero section dengan value proposition yang jelas
- Produk unggulan showcase
- Keunggulan Ecowise
- Tentang EcoFuture Labs
- Call-to-action section
- Footer dengan navigasi lengkap
- Mobile responsive navigation
- Smooth scroll animation
